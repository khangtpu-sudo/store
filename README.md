# English Quest: Tower of Words

Playable single-file MVP for an English-learning RPG.

## MVP included
- Grade/world selection 6–12
- RPG-style explorable map
- WASD / arrow-key movement + mobile controls
- Monsters and battle encounters
- Randomized question selection with anti-repetition
- Multiple choice, fill-in-the-blank, and word arrangement question types
- Correct/wrong battle outcomes and learning explanations
- EXP, level, HP, mana, ATK, DEF, gold and streak
- Inventory, potions, hints and skip tickets
- Shop
- Dungeon and Tower prototype floors + boss encounters
- Mistake Book with review/practice
- Player profile and learning stats
- Vietnamese / English UI toggle
- Local save via localStorage

## Run
Open `index.html` in a modern browser, or serve the repository with any static web server.

The code is intentionally dependency-free for the first playable prototype. The data structures are ready to be split into React/TypeScript + Phaser modules and backed by PostgreSQL/Supabase in the next phase.
